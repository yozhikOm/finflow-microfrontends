# UI-кит публикуется исходниками и не делится через `shared`

Общие компоненты и тема живут в npm-пакете `ui` (`@yozhikom/finflow-ui` на npmjs), который каждое приложение подключает при сборке со своей версией. В пакете лежат исходники (`.tsx` и `.module.css`), а не собранный `dist`: CSS Modules компилирует сборка потребителя со своим `uniqueName`, так что классы двух копий кита на одной странице не совпадают по построению. В `shared` Module Federation кит не входит: каждое приложение бандлит ту версию, с которой его тестировали, и дублирование байтов — осознанная цена этой предсказуемости.

## Consequences

- Нельзя «навести порядок» шагом сборки кита (Rslib и т. п.): имена классов захешируются один раз внутри `ui`, и разные версии кита у `shell` и remote-приложения получат одинаковые классы с разным CSS.
- Нельзя добавить `ui` в `shared` ради экономии байтов: remote-приложение получит в рантайме не ту версию, с которой его тестировали.
- Потребитель кита обязан собирать TS и CSS Modules. Все потребители — наши Rspack-сборки и витрина кита.
- React — `peerDependency` кита, иначе синглтон React из `shared` не сработает.
- Тема — CSS-переменные. `ui` поставляет `theme.css` с именами и значениями токенов, подключают его только `shell` и dev-обёртки remote-приложений; в сборку remote-приложения значения не попадают. Поскольку версии кита у `shell` и remote-приложения могут расходиться, в минорной версии токены только добавляются, а переименование или удаление токена — major.
- В ките нет сущностей FinFlow (счетов, категорий, транзакций). Тип значения Money в нём есть (`MoneyText`, `MoneyInput`). Компоненты с владельцем, как `AccountPicker`, остаются у владельца (ADR-0001).

## Considered Options

- Кит как remote-приложение Module Federation: отвергнут, недоступный `ui` ронял бы все приложения сразу, а визуальное изменение попадало бы в каждое без его ревью и выката.
- Готовая библиотека (Mantine, MUI) синглтоном в `shared`: отвергнута, своего кита нет, и у большинства таких библиотек runtime CSS-in-JS.
- Зависимость `file:../ui`: отвергнута, у кита не было бы версии, и любое приложение незаметно получало бы текущий `ui` при пересборке по другой причине.
- GitHub Packages: отвергнут, токен нужен даже для установки, в том числе при сборке на хостинге.
